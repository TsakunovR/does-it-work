# fixtures/bad-tests — заведомо плохой тестовый проект

Существует ради одного вопроса из Red flags: **«а этот линтер вообще может
что-то найти?»**. Здесь собраны нарушения всех правил `scripts/review_tests.py`,
по одному на правило. CI скилла прогоняет линтер по этой директории и проверяет,
что найдено **каждое** правило из `expected-rules.txt`.

Правило добавили в линтер → добавьте нарушение сюда и строку в `expected-rules.txt`,
иначе правило остаётся непроверенным.

Этот код никогда не запускается: он не должен быть рабочим, он должен быть плохим.
